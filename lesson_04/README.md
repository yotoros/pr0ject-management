# Практика 4. От требований к плану работ

Продолжайте в проекте «СЕВЕР». Основание для плана — требования R1–R5 и проверки P1–P5 версии 2 из [предыдущей практики](../lesson_03/README.md).

[Практика с пояснениями и кадрами](https://maximbytecamp.github.io/algorthimization_course_vvodnoe/upravlenie-programmnymi-proektami/lessons/04-plan-rabot/). Готовые названия, описания и сообщение о порядке работ находятся в [texts.md](texts.md).

## Что сделать

1. Создайте общую задачу «Подготовить резервирование последнего рюкзака». Добавьте ссылку на существующую задачу с требованиями версии 2.
2. Внутри общей задачи создайте две подзадачи: А1 — создание резерва, А2 — обработка срока, отмены и оплаты.
3. Отдельно в том же проекте создайте задачи Б — интерфейс покупателя, В — данные для проверки, Г — сквозная проверка. Назначьте ответственных. Если работаете самостоятельно, укажите себя.
4. В задачу В добавьте шесть пунктов чек-листа из `texts.md`. Пункты остаются невыполненными: на занятии вы планируете подготовку данных.
5. Замените ссылки-заглушки в описаниях адресами своих карточек. В чате общей задачи опубликуйте «Порядок работ по резервированию» со ссылками и ответственными.
6. Проверьте порядок: А1 и описание данных В начинаются сразу. А2 и Б требуют предварительного согласования данных с А1. Для начала Г нужны результаты А1, А2, Б, В и работающая тестовая среда.

Новый неоплаченный резерв действует 20 минут. Через 16 минут он ещё действует, через 21 минуту без оплаты — снят. Оплата на 10-й минуте закрепляет товар и после 20 минут.

В этой практике создаётся план будущей реализации. Все шесть новых карточек оставьте незавершёнными. Существующую задачу с требованиями и сценариями сохраняйте.
