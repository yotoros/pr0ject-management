# Тексты для CRM и запуска

Сначала замените квадратные скобки ссылками на собственные демонстрационные записи и укажите выбранных участников. Не отправляйте эти тексты реальному клиенту.

## CRM-запрос: название

```text
Запрос на проверку резервирования — СЕВЕР
```

## CRM-запрос: описание

```text
Заказчик просит подготовить к согласованию первый запуск резервирования в магазине «СЕВЕР». При наличии одного рюкзака только один заказ должен получить резерв. Если товар уже занят, покупатель должен увидеть понятное сообщение об отказе.

Нужно связать запрос с требованиями R1–R5 версии 2 и подготовленным планом работ. На этом этапе организуется запуск и готовится результат для согласования с заказчиком. Работу магазина можно указывать только после проверки в тестовой среде.

Границы: один рюкзак, количество 1. Поздняя оплата, возврат оплаченного товара, частичный заказ и изменение срока уже созданного резерва не входят.

Следующий шаг: уточнить состав запуска и связать CRM-запрос с координационной задачей проекта «СЕВЕР».
```

## Уточнение запроса

```text
Уточнение запроса

1. На согласование выносим маршрут запуска и подготовленные условия. Состояние работающего магазина фиксируется только после проверки.
2. В запуск входят результаты плана темы 4: создание резерва, обработка срока/отмены/оплаты, сообщение покупателю, данные и сквозная проверка.
3. Основание — R1–R5 и P1–P5 версии 2 из задачи «Подготовить проверки последнего товара».
4. Заказчик подтверждает состав запуска и получает ссылку на итоговую задачу.
5. За границами остаются поздняя оплата, возврат оплаченного товара, частичный заказ и изменение срока уже созданного резерва.
```

## Координационная задача: название

```text
Подготовить запуск резервирования для согласования с заказчиком
```

## Координационная задача: описание

```text
Цель: связать запрос заказчика из CRM с подготовленным планом проекта «СЕВЕР» и передать заказчику проверяемый результат запуска.

CRM-запрос: [ссылка на карточку запроса]
Клиент: [название связанной CRM-компании].

Основание:
— требования R1–R5 версии 2 и проверки P1–P5 из задачи «Подготовить проверки последнего товара» — [ссылка];
— общая задача и план темы 4 «Подготовить резервирование последнего рюкзака» — [ссылка];
— связанные работы А1, А2, Б, В и Г — [ссылки].

Что нужно сделать:
1. Проверить, что CRM-запрос содержит клиента, границы и следующий шаг.
2. Сопоставить запрос с планом темы 4, не создавая повторных карточек.
3. Зафиксировать роли: координатор, аналитик, исполнитель, проверяющий и заказчик.
4. Подготовить для заказчика ссылку на запрос, задачу запуска и список готовых/будущих результатов.
5. Записать, что фактический прогон магазина не выполнен, если тестовая среда недоступна.

Условия готовности:
— CRM-запрос связан с клиентом;
— в задаче есть ссылки на CRM и источник требований;
— видны связи с существующим планом;
— роли и границы указаны;
— итоговое сообщение не выдаёт план за готовую реализацию.
```

## Бриф запуска

```text
Бриф запуска резервирования — СЕВЕР

Клиент и CRM-запрос: [ссылки].
Основание: R1–R5 и P1–P5 версии 2 — [ссылка].
План: А, А1, А2, Б, В, Г — [ссылки].

Состав запуска: подготовить создание резерва, обработку срока/отмены/оплаты, сообщение покупателю, данные для проверки и будущий сквозной прогон.
Границы: один рюкзак, количество 1; поздняя оплата, возврат оплаченного товара, частичный заказ и изменение срока уже созданного резерва не входят.

Роли: координатор — [имя]; аналитик — [имя]; исполнитель — [имя]; проверяющий — [имя]; заказчик — [роль или имя].

Фактический прогон магазина не выполнен до появления тестовой среды. Результат этой работы — связанный маршрут запуска для согласования.
```
