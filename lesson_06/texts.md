# Тексты для рабочего пространства

Замените квадратные скобки ссылками на существующие записи и имена — выбранными участниками. Работайте с уже созданной задачей В; не меняйте её чек-лист и не выдавайте план за выполненную реализацию.

```text

```

## Рабочий бриф: название

```text
Бриф проверки резервирования — подготовка данных
```

## Рабочий бриф: текст

```text
Проект: «СЕВЕР».
Рабочий фрагмент: В «Подготовить данные для проверки резервирования».

Основание: R1–R5 версии 2. Проверки: P1–P5.

Входные данные: один рюкзак, количество 1, резерв действует 20 минут.

Что готовим: данные и описание двух состояний товара для будущего независимого прогона.
1. Резерв действует: повторный заказ не получает резерв.
2. Срок резерва истёк: товар снова доступен для нового резерва.

Роли: координатор — [имя]; аналитик — [имя]; исполнитель — [имя]; проверяющий — [имя]; заказчик — [роль или имя].

Связи: задача В — [ссылка]; задача Г — [ссылка]; требования и проверки — [ссылка].

Границы: поздняя оплата, возврат оплаченного товара, частичный заказ и изменение срока уже созданного резерва в этот фрагмент не входят.

Решение: оба состояния товара включены в подготовленные данные. Проверяющий сверяет их с R3 и P3.
```

## Вопрос для обсуждения задачи В

```text
Вопрос для работы В

Для проверки P3 нужно показать состояние товара до окончания резерва и после окончания 20 минут. Нужно ли включить оба состояния в подготовленные данные?
```

## Решение для обсуждения задачи В

```text
Решение

Да. Бриф содержит два состояния: резерв действует — повторный заказ не получает резерв; срок истёк — товар снова доступен для нового резерва. Проверяющий сверяет оба состояния с R3 и P3.
```
